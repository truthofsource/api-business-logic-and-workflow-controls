# Source mapping

[Machine mapping](source-map.json) records the original file hashes and public destinations. Names, role prefixes and example targets are changed consistently; no employee records, credentials, live IDs, tokens or Terraform state are included.

The wage rule functions/types are extracted before the SQL-store factory, with a small local error/ID adapter. Runtime SQL imports are omitted from that pure copy; full actual store/route source remains under reference. Two original discard tests change only the import extension for Node execution. Eight new tests exercise the extracted rules. Node strips types without a full application type check.

The local viewer and demonstration are new fictional references and are explicitly labeled. Dated implementation context is not a new cloud readback. The public runtime uses pure rules and a small error adapter. It does not validate JWTs, open SQL, prove distributed concurrency or complete a payroll transaction.
